# BMKT 670 Final Project: Seattle Seahawks Home Game Attendance ETL

End-to-end ETL pipeline and PostgreSQL (bmkt670_seahawks) star schema for modeling Seattle Seahawks home game attendance at Lumen Field.

## Setup & Run
1. Configure .env with DB_HOST, DB_PORT, DB_NAME=bmkt670_seahawks, DB_USER, and DB_PASSWORD.
2. Activate .venv and run: python run_pipeline.py
